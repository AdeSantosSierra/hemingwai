# Newscore

Herramienta para analizar noticias con ayuda de IA y ofrecer una evaluación de su calidad periodistica.

## Que incluye

- Motor de analisis en Python
- API backend en Node.js
- Frontend web en React
- Extension de navegador para detectar y consultar noticias

## Como funciona

La herramienta analiza una noticia y devuelve puntuaciones, alertas y una valoracion general a partir de varios criterios de calidad informativa.

## Ejecucion local

### Dependencias Python

```bash
pip install -r requirements.txt
```

### Backend

```bash
cd servidor_api
npm install
npm start
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```

## Requisitos

- Python 3
- Node.js
- Variables de entorno configuradas
